# Cute-Calculator
A simple but feature-rich command-line calculator built with Python 🐍🎀  This project started as a basic calculator and gradually grew into a more complete application with multiple mathematical operations, calculation history, JSON storage, and the ability to clear saved history.  💕 Simple code. Useful features. A little personality.
📌 About the Project

Cute Calculator is a Python-based command-line calculator designed to practice core programming concepts while building something interactive and useful.

Instead of only supporting basic addition and subtraction, the calculator includes several mathematical operations and remembers previous calculations using a JSON file.

The project also includes a history management system, allowing users to view their previous calculations or clear them whenever they want.

✨ Features
🧮 Mathematical Operations
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
📐 Floor Division
⚡ Power
🌱 Square Root
📜 Calculation History

Calculations are saved in history.json in a simple calculator-style format:

4 + 5 = 9
10 ÷ 2 = 5.0
3 × 6 = 18
√25 = 5.0
💾 Persistent Memory

The calculation history is stored in a JSON file, allowing it to remain available even after closing the program.

🗑️ Clear History

Users can remove their saved calculation history whenever they want.

🎀 Interactive CLI

A simple menu with emojis and friendly messages makes the command-line experience more fun.

🛠️ Technologies Used
