##📌 About the Project


A simple but feature-rich command-line calculator built with Python 🐍✨

This project started as a basic calculator and gradually grew into a more complete application with multiple mathematical operations, calculation history, JSON data storage, and the ability to clear saved history.

> 🌸 **Simple code, useful features, and a little personality.**

---

## ✨ What Does It Do?

Cute Calculator lets you perform different mathematical operations directly from the terminal.

You can:

* ➕ Add multiple numbers
* ➖ Subtract multiple numbers
* ✖️ Multiply multiple numbers
* ➗ Divide multiple numbers
* 📐 Perform floor division
* ⚡ Calculate powers
* 🌱 Calculate square roots
* 📜 View your previous calculations
* 🗑️ Clear your saved calculation history

The calculator stores its history in a `history.json` file, so your previous calculations can remain available even after closing the program.

---

## 🌸 Features

### 🧮 Multiple Operations

Perform several common mathematical calculations from one simple menu.

### 📜 Calculation History

View previous calculations in a calculator-style format, for example:

```text
4 + 5 = 9
20 ÷ 2 = 10.0
3 × 7 = 21
√25 = 5.0
```

### 💾 Persistent Storage

Calculation history is stored in a JSON file, allowing the data to remain between program runs.

### 🗑️ Clear History

Delete your saved calculation history whenever you want.

### 🎀 Friendly CLI

A colorful command-line interface with emojis makes the calculator a little more fun to use.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/cute-calculator.git
```

### 2. Open the project folder

```bash
cd cute-calculator
```

### 3. Run the program

```bash
python calculator.py
```

No external packages are required. 🎀
